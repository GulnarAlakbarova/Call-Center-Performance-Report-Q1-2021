# Call-Center-Performance-Report-Q1-2021
Call center performance analysis using Power BI – Q1 2021

## Project Overview

An analysis of call center performance during the first quarter of 2021, focusing on call activity, issue resolution, employee performance, and customer satisfaction.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX

## Key Analysis

- Answered vs. unanswered calls
- Resolved vs. unresolved issues
- Regional performance analysis
- Customer satisfaction by call topic
- Employee performance comparison
- Monthly call resolution trends
- Customer age group analysis

## Conclusion

This project provides insights into call center operations, helping evaluate service efficiency, employee performance, and customer satisfaction.
